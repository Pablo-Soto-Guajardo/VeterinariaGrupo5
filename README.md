# Veterinaria San Marcos - "San Marcos Digital"

Proyecto incremental desarrollado para la asignatura Desarrollo FullStack II (DSY1104) de Duoc UC. 
Consiste en el diseno y maquetacion de una plataforma web para la gestion de citas clinicas y catalogo de servicios de la Veterinaria San Marcos, ubicada en Rancagua.

## Estado del Proyecto (Fase de Estructura y Navegacion)
En esta primera etapa se ha establecido el entorno inicial del proyecto junto con sus paginas principales:
*   Estructura Semantica: Creacion del punto de entrada estructurado con HTML5 semantico (`index.html`).
*   Paginas del Sitio: Incorporacion de las paginas principales de la tienda (`nosotros.html`, `productos.html` y `producto-detalle.html`).
*   Arquitectura de Carpetas: Organizacion limpia de recursos estaticos mediante la estructura estandarizada de carpetas (`assets/css/` y `assets/js/`).

## Tecnologias Utilizadas
*   HTML5: Marcado semantico y jerarquia estructural.
*   CSS3: Archivo externo inicializado para la futura identidad visual.
*   JavaScript Vanilla: Archivo de comportamiento base enlazado.
*   git y GitHub: Control de versiones y trabajo colaborativo.

## Instrucciones de Ejecucion
Para visualizar y probar la interfaz del proyecto de manera local:
*   Clonar este repositorio en tu maquina de desarrollo.
*   Abrir el archivo `index.html` directamente en tu navegador web de preferencia, o bien hacer clic derecho sobre el en VS Code y seleccionar Open with Live Server.
